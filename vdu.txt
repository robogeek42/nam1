VDU commands on NAM1

Implementation of some BBC basic style VDU commands in the NAM1 ehBasic

====================================================================+---------------------------------+
|     | Extra  |              |                                     |                                 |
| VDU | Bytes  | Parameters   | Description                         | BBC VDU command                 |
+-------------------------------------------------------------------+---------------------------------+
|   0 | 0      |              | Does Nothing                        | Does Nothing                    |
+-------------------------------------------------------------------+---------------------------------+
|  12 | 0      |              | CLS                                 | Clear Text Area CTS             |
+-------------------------------------------------------------------+---------------------------------+
|  17 | 1 or 2 | M2:COL,CHAR  | Set colour of character CHAR to COL | Select Text Colour              |
|     |        | M4:COL       | Set colour under cursor pos to COL  |                                 |
+-------------------------------------------------------------------+---------------------------------+
|  23 | 9      | CHAR,bytes*8 | Redefine character CHAR             | Define display char             |
+-------------------------------------------------------------------+---------------------------------+
| >32 | *      |              | Print chrs as CHR$()                |                                 |
+-------------------------------------------------------------------+---------------------------------+
|     |        |              |                                     |                                 |
+-------------------------------------------------------------------+---------------------------------+
